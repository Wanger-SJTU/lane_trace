# 随机颜色分配功能

## 功能说明

当导入JSON文件时，如果泳道没有指定颜色，系统会自动分配一个随机颜色。

## 实现细节

**颜色池：**
```javascript
const predefinedColors = [
  '#3b82f6', // 蓝色
  '#8b5cf6', // 紫色
  '#ec4899', // 粉色
  '#f59e0b', // 橙色
  '#10b981', // 绿色
  '#06b6d4', // 青色
  '#6366f1', // 靛青
  '#f97316'  // 深橙色
];
```

**随机分配逻辑：**
1. 预定义颜色数组被随机打乱
2. 每个没有颜色的泳道按顺序获取颜色
3. 如果泳道数量超过颜色数量，循环使用

## 使用示例

**没有指定颜色的JSON：**
```json
{
  "version": "2.0",
  "swimlanes": [
    {
      "name": "Service A",
      "blocks": [
        {"name": "Task", "offset": 0, "size": 100}
      ]
    },
    {
      "name": "Service B",
      "blocks": [
        {"name": "Task", "offset": 200, "size": 150}
      ]
    }
  ]
}
```

**导入后会自动分配颜色：**
- Service A → 随机颜色（如 #3b82f6 蓝色）
- Service B → 随机颜色（如 #8b5cf6 紫色）

## 特性

**✅ 每次导入颜色不同：**
- 颜色数组每次都会随机打乱
- 相同的JSON文件会产生不同的颜色组合

**✅ 视觉区分清晰：**
- 预定义颜色经过精心挑选，确保视觉上容易区分
- 避免相似颜色分配给相邻泳道

**✅ 支持大量泳道：**
- 8种预定义颜色
- 超过8个泳道时会循环使用

## 手动指定颜色

如果想要特定颜色，仍然可以在JSON中指定：

```json
{
  "swimlanes": [
    {
      "name": "Important Service",
      "color": "#ef4444",  // 手动指定红色
      "blocks": [...]
    },
    {
      "name": "Normal Service",  // 没有颜色字段
      "blocks": [...]            // 自动分配随机颜色
    }
  ]
}
```

## 测试文件

`test-random-colors.json` - 包含4个没有颜色的泳道，每次导入会产生不同的颜色组合。

## 优势

1. **简化JSON编辑** - 不需要为每个泳道指定颜色
2. **视觉多样性** - 每次导入都有不同的视觉效果
3. **灵活性** - 可以手动指定重要泳道的颜色
4. **用户友好** - 新用户不需要了解颜色系统
